# Carpeta de Sonidos

Esta carpeta está destinada para los archivos de audio del portfolio.

## Archivos necesarios:

Coloca aquí tus archivos de sonido en formato `.mp3`:

- `hover.mp3` - Sonido al pasar el mouse sobre elementos interactivos
- `click.mp3` - Sonido al hacer click en botones o enlaces
- `select.mp3` - Sonido al seleccionar proyectos

## Sugerencias de sonidos:

Puedes obtener sonidos gratuitos de:
- [Freesound.org](https://freesound.org)
- [Zapsplat.com](https://www.zapsplat.com)
- [Mixkit.co](https://mixkit.co/free-sound-effects/)

## Características recomendadas:

- **Formato**: MP3
- **Duración**: 0.1 - 0.5 segundos
- **Volumen**: El código ya incluye control de volumen (30%)
- **Tipo**: Sonidos sutiles, tipo "beep" o "click" de teclado mecánico

## Ejemplo de estructura:

```
sounds/
├── hover.mp3
├── click.mp3
└── select.mp3
```

Una vez que agregues los archivos de sonido, el portfolio los reproducirá automáticamente al interactuar con los elementos.
